
# 📂 FULL DATA ANALYSIS PROJECTS

This repository is a dedicated collection of **End-to-End Data Analysis Case Studies**. These projects are designed to bridge the gap between raw data and actionable business insights by applying rigorous analytical frameworks to real-world scenarios.

## 🎯 Project Scope
The projects in this folder focus exclusively on **Core Data Analytics** and **Applied Statistics**. 

> **Note:** This collection does not cover Machine Learning (Scikit-Learn) or Deep Learning (TensorFlow/PyTorch). Instead, it focuses on the "Human-in-the-Loop" analytical process—cleaning, exploring, and statistically validating data to drive decision-making.

---

## 🛠️ Core Competencies Covered
Each project in this directory demonstrates proficiency in the following pillars:

* **SQL for Data Extraction**: Complex joins, CTEs, and window functions to pull meaningful subsets from relational databases.
* **Exploratory Data Analysis (EDA)**: Advanced data cleaning, outlier detection, and pattern recognition using **Pandas**, **NumPy**, and **Matplotlib/Seaborn**.
* **Statistical Testing**: Moving beyond "gut feelings" by applying **Hypothesis Testing**, **ADF Tests**, **Levene’s Test**, and **Granger Causality** to ensure results are statistically significant.
* **Time Series Analysis**: Special focus on trend decomposition, seasonal adjustments, and forecasting using classical econometric models like **SARIMAX**.
* **Data Visualization**: Communicating findings through clear, professional charts and **Power BI** dashboards to translate numbers into stories.

---

## 📈 Methodology
Every case study follows a structured workflow:
1.  **Business Problem Definition**: Identifying the core question.
2.  **Data Wrangling**: Cleaning and preparing messy, real-world datasets.
3.  **Statistical Validation**: Proving relationships between variables.
4.  **Actionable Insights**: Providing concrete recommendations based on the analysis.
